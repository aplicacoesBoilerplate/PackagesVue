# @aplicacoesboilerplate/ui-core

Componentes construídos com Vue nativo, com Vue como peer dependency. O pacote não exige PrimeVue ou Vuetify.

## Instalação e requisitos

<PackageInstall />

## API atual

O ponto de entrada exporta BaseOverlay e o tipo IBaseOverlayProps. O catálogo gerado preserva as propriedades, eventos, snippets e exemplos extraídos dos fontes.

[Referência e preview de BaseOverlay](../generated/ui-core/base-overlay) · [IBaseOverlayProps](../generated/ui-core/i-base-overlay-props)

## Relação com as outras bibliotecas

ui-prime-vue e ui-vuetify têm nomes e versões próprios. Elas ainda não declaram dependência deste pacote, portanto uma mudança no core não implica incremento automático dessas bibliotecas.
